# 📚 Library Management System (Flask + MongoDB)

A feature-rich web application for managing users, books, and content using Flask, MongoDB, and Bootstrap.

---

## 🚀 Features

- 👤 User and Admin Registration/Login
- 🔐 Secure password hashing & strength validation
- 🔁 Password reset via OTP email (Gmail)
- 📚 Upload, view, edit, and delete books (PDF, DOCX, EPUB, TXT)
- 🔎 Search and filter by category
- 📄 Read books online in viewer (PDF/Iframe/Text/HTML)
- 🧑‍💻 Admin dashboard for managing users and books
- ❤️ Wishlist, About page, and user profile
- 📩 Email notifications using Gmail SMTP
- 🌐 Clean, responsive frontend

---

## 🧪 Tech Stack

- Python 3.11
- Flask
- MongoDB (with PyMongo)
- Bootstrap + HTML/CSS
- JavaScript (Pure)
- Gmail SMTP for email delivery
- `python-dotenv` for credential safety
